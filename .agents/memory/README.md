# Agent memory

This directory contains repository-specific **non-normative** knowledge whose rediscovery would be wasteful.

Use it for durable architecture notes, decisions/rationale, investigations, platform/tool quirks, diagnostics, failed approaches, migration evidence, and similar context when source/tests or human-facing documentation are not the right home.

Memory never overrides current baseline or local instructions merely because it exists.

Do not preload this directory. Read only task-relevant memory.

Do not create empty category directories for symmetry. Introduce categories when useful knowledge actually needs them, and prefer updating an existing note over creating competing memory.
