# Initiatives

This directory holds structured, intentionally unfinished work or technical debt that is more concrete than a reminder but is **not itself executable agent work**.

An initiative:

- is not part of Dispatch;
- does not authorize implementation;
- is not claimed or marked `IN_PROGRESS`;
- may link executable tasks without duplicating their mutable state/dependencies.

A useful initiative normally records:

- Status
- Goal
- Current state / coverage
- Known gaps
- Deliberate boundaries / deferred work
- Related executable tasks
- Promotion / closure criteria

Use [`../reminders.md`](../reminders.md) for lightweight "do not forget this" intent. Use [`../tasks.md`](../tasks.md) and task specifications when bounded work is sufficiently specified and authorized.

Do not ingest every initiative during routine startup. Read only initiatives relevant to current work.
