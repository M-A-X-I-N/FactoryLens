# Reminders

This file holds lightweight future intent that is deliberately **not executable agent work**.

A reminder:

- is not part of Dispatch;
- carries no authorization to act;
- must not be silently executed or promoted by an agent;
- becomes executable only after deliberate promotion into sufficiently specified task work.

Keep this register simple. When an idea becomes a structured multi-phase concern with meaningful known gaps but is still not executable, move it into [`initiatives/`](initiatives/) rather than turning this file into a second task backlog.
