# FL-C240 — Add source navigation

## State

`QUEUED`

Dependencies: `FL-C230`

## Description

Navigate Rider users from FactoryLens roots/nodes/edges to trustworthy source locations.

## Requirements

- Use supported navigation targets from the analyzer model.
- Prefer trustworthy call site, then definition, then declaration as available.
- Do not manufacture locations when the semantic backend did not provide a trustworthy source.
- Handle unavailable/stale navigation targets visibly.

## Acceptance criteria

Activating a root/node/edge navigates to the best supported declaration, definition, or call location without inventing locations clangd did not actually identify.

## Validation

Exercise each supported navigation target shape against controlled and real-source specimens.
