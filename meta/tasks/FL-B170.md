# FL-B170 — Add a headless developer CLI/integration harness

## State

`QUEUED`

Dependencies: `FL-B150`, `FL-B160`

## Description

Provide a supported developer-facing headless path that exercises the analyzer without Rider.

## Requirements

- Initialize a supported analyzer session for a configured workspace/target.
- List discovered roots from supported root providers.
- Select and expand a root through supported graph/call APIs.
- Emit useful human-readable output.
- Provide a machine-readable result form suitable for integration validation.
- Surface configuration/backend/query failures honestly.

## Constraints / non-goals

- This is a development/test surface, not necessarily a promised end-user CLI product.
- Do not duplicate semantic logic in CLI presentation code.

## Acceptance criteria

A supported command can initialize the analyzer, list roots, expand a selected root, and emit human-readable plus machine-readable results without Rider.

## Validation

Exercise the CLI against controlled fixtures and at least one configured real workspace.
