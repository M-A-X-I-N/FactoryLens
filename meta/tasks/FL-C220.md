# FL-C220 — Add the framework-root explorer

## State

`QUEUED`

Dependencies: `FL-C210`

## Description

Expose useful supported framework roots in Rider.

## Requirements

- List discovered roots with useful labels.
- Show enough provenance/evidence to explain why a root exists.
- Prefer useful/high-value roots by default.
- Avoid drowning the user in every semantically valid but low-value generic override.
- Represent loading/degraded/error states honestly.

## Acceptance criteria

A Rider surface lists discovered roots with useful labels and provenance, and does not drown the user in every semantically valid but low-value override by default.

## Validation

Use controlled root-discovery data plus representative real-workspace roots in Rider.
