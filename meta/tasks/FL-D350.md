# FL-D350 — Product packaging, compatibility policy, and installation UX

## State

`FROZEN`

Dependencies: `FL-C260`

## Description

Turn the proven product prototype into something installable/updatable with an explicit compatibility contract.

## Requirements

- Define supported Rider/Satisfactory/UE/SML combinations.
- Provide predictable installation/update behavior.
- Surface compatibility mismatches clearly.
- Avoid promising unsupported combinations.

## Acceptance criteria

FactoryLens can be installed/updated predictably and declares which Rider/Satisfactory/UE/SML combinations it supports.

## Validation

Exercise supported install/update paths and compatibility checks on declared combinations.
