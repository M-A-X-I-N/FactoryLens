# FL-C210 — Connect Rider project lifecycle to the analyzer lifecycle

## State

`QUEUED`

Dependencies: `FL-C200`

## Description

Wire Rider project lifecycle events to supported analyzer session lifecycle.

## Requirements

- Opening a supported project starts or reuses the semantic service predictably.
- Closing/disposal stops owned analyzer resources cleanly.
- Reload/reconfiguration restarts or refreshes state predictably.
- Failures are visible to the frontend.
- Respect Rider/project coroutine/lifecycle ownership rather than leaking it into the core API.

## Acceptance criteria

Opening, closing, and reloading a supported project starts, reuses, restarts, and stops the semantic service predictably; failures are visible rather than silent.

## Validation

Exercise open/close/reload/error paths in controlled plugin tests and the supported Rider baseline.
