# FL-D320 — Add UHT/reflection metadata ingestion

## State

`FROZEN`

Dependencies: `FL-C260`

## Description

Use Unreal Header Tool/reflection metadata to enrich roots/edges that ordinary C++ call semantics cannot represent directly.

## Requirements

- Support useful metadata for RPCs, NetMulticast, RepNotify, BlueprintNativeEvent, and BlueprintImplementableEvent where evidence is trustworthy.
- Preserve generated/reflection provenance distinctly from generic authored external overrides.
- Avoid pretending generated metadata implies ordinary direct-call semantics.

## Acceptance criteria

RPC, NetMulticast, RepNotify, BlueprintNativeEvent, and BlueprintImplementableEvent declarations can contribute appropriately qualified roots/edges from UHT/generated metadata.

## Validation

Use controlled generated/reflection fixtures plus representative real Satisfactory source when thawed.
