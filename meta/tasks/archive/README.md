# Task archive

This directory contains terminal task history removed from the active scheduling surface.

- `product-history/` stores stable-ID records for completed historical FactoryLens product tasks migrated from the legacy roadmap.
- Completed migration/task blocks may be moved here intact once every task in the block is terminal.

Archive records preserve useful identity, scope, acceptance evidence, and links without duplicating mutable active scheduling state. Git history remains authoritative for historical claims and checkpoint chronology.
