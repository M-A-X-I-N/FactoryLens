# FL-C200 — Create the minimal Rider plugin skeleton

## State

`QUEUED`

Dependencies: `FL-B190`

## Description

Establish the supported Rider-side plugin entry surface on top of the validated analyzer foundation.

## Requirements

- Rider loads FactoryLens on the chosen supported Rider baseline.
- The plugin can detect/open a supported Satisfactory project.
- Keep semantic/compiler logic outside Rider UI code.
- Surface configuration failures rather than silently doing nothing.

## Constraints / non-goals

- No polished explorer UI is required yet.
- Do not make Rider the semantic source of truth.

## Acceptance criteria

Rider loads FactoryLens in the chosen supported Rider baseline and the plugin can detect/open a Satisfactory project without yet requiring polished UI.

## Validation

Build/package the plugin and exercise loading/project detection in the supported Rider baseline.
